### Penjelasan Sistem Peminjaman Buku Perpustakaan Fakultas Teknik

**Sistem Peminjaman Buku Perpustakaan Fakultas Teknik** adalah program sederhana berbasis Python yang digunakan untuk mengelola proses peminjaman buku di perpustakaan. Program ini menyediakan beberapa pilihan menu, yaitu **meminjam buku, menghapus peminjaman, dan menyelesaikan proses**.

Program memiliki daftar beberapa buku yang tersedia, seperti *Dasar-Dasar Robotika, Pemrograman Python, Administrasi Jaringan, Rekayasa Perangkat Lunak,* dan *Pemrograman Web*. Pengguna dapat memilih buku berdasarkan nomor yang tersedia. Sistem juga melakukan validasi agar buku yang sama tidak dapat dipinjam dua kali.

Selain itu, pengguna dapat menghapus buku yang sebelumnya sudah dipinjam. Setelah proses selesai, program akan menampilkan **seluruh daftar buku yang berhasil dipinjam**.

**Tujuan sistem** ini adalah untuk mempermudah proses pencatatan peminjaman buku serta menerapkan konsep dasar pemrograman Python seperti **tuple, list, perulangan (`for` dan `while`), percabangan (`if-elif-else`), input, dan validasi data**.
